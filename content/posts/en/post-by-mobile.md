This page is distributed via Vercel, and the repository uses Git. Posts are written using Markdown files, and the structure is such that `postdata` receives those files, `postdetail` renders the detail page, and `posts` displays the list of posts. I thought there wouldn&#39;t be a way to post without the local project files, so I considered just going with the easier option of using a CMS, but wait, isn&#39;t the post updated just by adding files and committing via the GitHub app or a mobile web browser...? So, does it work well?
